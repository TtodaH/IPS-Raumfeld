Schalter

Benötigt: Symcon >= 5.0

Ein Schalter kann An (true) oder Aus (false) geschaltet werden.

Voraussetzungen

Ein Schalter ist eine Variable mit der Darstellung Schalter. Um diese Darstellung zu verwenden muss die Variable folgende Bedingungen erfüllen:

  • Typ Boolean
  • Eingerichtete Variablenaktion

Parameter

Parameter Beschreibung
Individuelle Icons passend zum Wert Falls gesetzt, kann für true und false je individuelle Icons gewählt werden. Ansonsten wird ein einzelnes Icon gewählt, welches immer dargestellt wird
Icon Icon welches dauerhaft auf dem Schalter angezeigt wird (nur verfügbar wenn "Individuelle Icons passend zum Wert" nicht gesetzt ist)
Icon für true Icon welches auf dem Schalter angezeigt wird wenn die Variable den Wert true hat (nur verfügbar wenn "Individuelle Icons passend zum Wert" gesetzt ist)
Icon für false Icon welches auf dem Schalter angezeigt wird wenn die Variable den Wert false hat (nur verfügbar wenn "Individuelle Icons passend zum Wert" gesetzt ist)
Farbe des Leuchtens wenn aktiv Konfiguriert die Farbe des Leuchtens um den Schalter, wenn dieser aktiv ist, die Variable also den Wert true hat
Intensität des Leuchtens wenn aktiv Konfiguriert die Intensität des Leuchtens um den Schalter, wenn dieser aktiv ist, die Variable also den Wert true hat
Verwendung der Variable Verwendung der Variable in zusammengefassten Darstellungen. Der Wert wirkt sich nicht direkt auf die Darstellung der Variable auf, sondern nur auf deren Verwendung in zusammengefassten Darstellungen.

Darstellung als Legacy-Profil

Verwendet eine Variable die Darstellung Legacy Profil, so wird diese als Schieberegler darstellt, falls sie zusätzlich folgende Bedingungen erfüllt:

  • Kein Variablenprofil gesetzt oder Variablenprofil "~Switch" oder "~Mute"

Bei der Verwendung eines Variablenprofils werden einige Parameter des Schiebereglers abgeleitet

Verwendung der Variablen

Die Verwendung hängt vom Profilnamen ab.

  • An/Aus für Profilnamen
    • ~Switch
    • Kein Profil
  • Stumm schalten für Profilnamen "~Mute"
